# From zero: SuperGrok + Grok Bot + this desk

Windows laptop. Grok Bot desktop already installed. SuperGrok account.

## 0. Mental model (2 minutes)

- **SuperGrok** = you think with it.
- **Grok Bot** = you hand it a job and walk away. It has its own cloud computer. All Bots on your account share `/workspace` files.
- **Skill** = saved method (`/` in the Bot composer).
- **Routine** = that method on a clock.
- **Automation** (grok.com/automations) = SuperGrok on a clock. Different product from a Bot routine.
- **Grok Build** (`grok` in a terminal) = coding agent for this repo. Skip it unless you are changing the HTML/markdown.

Official: https://x.ai/bot · https://docs.x.ai/grok-bot/skills-routines-and-automations · https://x.ai/news/grok-automations · https://grok.com/connectors

## 1. Create four Bots (12 minutes)

In Grok Bot desktop:

1. Ctrl+N → Create new agent
2. Bot actions → Edit Profile
3. Paste name + description from the matching file in bots/
4. Repeat for: F3-Chief, F3-Research, F3-Listen, F3-Comms

Do not create a fifth. Paid Media is a Grok Bot template name — do not use it. You have not run ads.

Follow the rest of the steps in this file on GitHub after the first commit lands.
