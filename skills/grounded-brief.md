# Skill: grounded-brief

1. When to use: a human pastes company URLs and wants a 1-page B2B tech-marketing brief.
2. Inputs: source files with verbatim quotes + URLs. No prior memory of facts.
3. Sequence: list claims that appear on the pages → group into positioning / buyer / proof / gaps → build a competitor table only from quoted homepage lines.
4. Validate: every sentence maps to a URL. Unmapped sentences are deleted, not footnoted as likely.
5. Return: BRIEF.md
6. Approval: human before the brief leaves the folder.
