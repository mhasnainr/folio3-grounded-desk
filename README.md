# Grounded Desk

This repo is a **web app**, not a Grok Bot you can log into.

## Open the app (do not open this README and call it the product)

After GitHub Pages is on:
https://mhasnainr.github.io/folio3-grounded-desk/

Until Pages builds, use:
https://cdn.jsdelivr.net/gh/mhasnainr/folio3-grounded-desk@main/index.html

On the page: **Load Folio3 demo** → **Build pack** → tap Brief / Drafts / Cuts.
Or paste public URLs → Fetch pages → Build pack.

GitHub file view shows source code. That is not the app.
