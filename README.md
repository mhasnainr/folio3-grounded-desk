# Folio3 Grounded Desk

Work sample for Folio3 **MTO Marketing** (tech marketing, performance marketing, digital analytics).

Not a claim that I already run paid media. Not a Folio3 product. A 1-day, source-grounded marketing ops desk: collect public pages → brief → drafts → kill unsupported claims.

**Recruiter / marketer: start here (2 minutes)**

1. Open the static demo: [docs/index.html](docs/index.html) (enable GitHub Pages on `/docs` or open the file).
2. Read [`sample-output/BRIEF.md`](sample-output/BRIEF.md) and [`sample-output/CONTENT.md`](sample-output/CONTENT.md).
3. Read [`sample-output/PROCESS.md`](sample-output/PROCESS.md) — what the model invented and what I cut.
4. Bot profiles you can import into Grok Bot are in [`bots/`](bots/).

I am a 6th-semester IoBM BS Mathematics & Economics student (CGPA 2.63, expected Dec 2027). This desk is the job argument. Eligibility on the campus email was final-year Marketing / Media / Communications. I did not fake that.

## What each Grok surface is for

| Surface | What it is | Used for here |
|---|---|---|
| SuperGrok (grok.com) | Chat + research + writing | Brief, drafts, red-team |
| [Grok Bot](https://x.ai/bot) | Named agents on a cloud PC; browser, files, routines | Collect pages, dump X posts, never publish |
| [Automations](https://grok.com/automations) | Scheduled / email-triggered SuperGrok jobs | Monday competitor scan |
| [Connectors](https://grok.com/connectors) | Gmail, Drive, etc. | Optional: save briefs to Drive. Do not connect Folio3 systems. |
| [Skills](https://grok.com/skills) / Bot `/` skills | Reusable instructions | `grounded-brief`, `grounded-draft`, `red-team` |
| [Grok Build](https://docs.x.ai/build/overview) | Terminal coding agent | Edit this repo, not the marketing workflow |

A Folio3 recruiter **cannot sit inside my Grok Bot**. Sharing a Bot only copies the profile if they already have the app. That is why the demo and `sample-output/` exist.

## Hard rules (also in every Bot description)

- Public URLs only. No unpublished metrics.
- No outbound to Folio3, clients, or prospects.
- Drafts stay drafts until a human publishes.
- If a sentence has no source, delete it.
- Do not pretend this desk has GA or Ads Manager access.
